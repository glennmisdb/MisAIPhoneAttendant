# MIS AI Phone Attendant

A .NET 9 pilot that connects a Twilio test number to Twilio ConversationRelay, uses OpenAI to answer basic questions about Micro Integration Services, qualifies prospective leads, and transfers callers to a human when requested.

The configured transfer destination is supplied through `TRANSFER_NUMBER`; use `+16093674818` for the pilot.

Full setup and operating instructions are included below as the project is completed.
